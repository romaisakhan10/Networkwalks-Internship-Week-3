# Module 2: Password Cracking with Networkwalks Tools

## 1. Project Overview

This module explores password auditing using two online tools developed by Networkwalks:

- Networkwalks Hash Calculator
- Networkwalks Password Cracker

The objective was to understand how password hashes are extracted from protected PDF files and how password auditing tools attempt to recover the corresponding password.

## 2. Learning Objectives

- Understand password hashing.
- Explore online hash extraction tools.
- Learn how to generate PDF password hashes.
- Understand the password-auditing process.
- Verify the results using the original protected PDF.

## 3. Tools Used

| Tool | Purpose |
|---|---|
| Networkwalks Hash Calculator | Extracting PDF hashes |
| Networkwalks Password Cracker | Password auditing |
| Web Browser | Accessing online tools |
| Windows | Operating environment |

## 4. Practical Implementation

### Step 1: Access the Hash Calculator

Opened the Networkwalks Hash Calculator in a web browser.

### Step 2: Upload the Protected PDF

Uploaded the supplied protected PDF to the Hash Calculator.

### Step 3: Generate the Hash

The tool generated a PDF password hash beginning with `$pdf$`.

### Step 4: Copy the Hash

Copied the complete generated hash for the next stage.

### Step 5: Access the Password Cracker

Opened the Networkwalks Password Cracker.

### Step 6: Perform Password Auditing

Entered the extracted hash into the Password Cracker and started the auditing process.

### Step 7: Verify the Result

Used the recovered password to open the protected PDF and checked that it opened successfully.
